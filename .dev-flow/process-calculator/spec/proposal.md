# 化工工艺计算工作台｜产品方案

## 背景与目标

面向负责公用工程和液体管线设计的化工工艺工程师，以及需要复核选型依据的同事。以冷却水支管为例，工程师要在正常、最大流量下比较候选管径。最大流量修订后，需要重算所有受影响的方案，再把输入、计算和选型依据一起更新到计算书。常见的手工环节包括复制计算表、核对单位及取值、把结果抄入报告，以及判断新旧报告用的是哪一版条件。

产品将一条管线的**工况、候选方案、取值依据、计算结果、限值与选型理由**保存在同一份计算单。设计人员可改一个输入重算整张对比表，校审人员可从计算书回查公式及取值，接手人员可导入项目文件继续工作。产品给出的校核结论仅对应用户录入的限值和所选计算方法。工程师记录最终选型和理由。

在冷却水支管演示中，正常流量为 30 m³/h，最大流量由 45 调至 55 m³/h。按演示项目自填的流速上限 2 m/s、阻力压降上限 35 kPa，实际内径 102.3 mm 的方案在最大工况下由满足限值变为超限，阻力压降约由 31.05 升至 45.64 kPa。实际内径 128.2 mm 的方案在最大工况下的阻力压降约由 10.79 升至 15.82 kPa，仍满足这两个限值。用户可打开新版计算书查明变化来自哪一项输入。这些限值仅用于展示项目校核流程。

试点用取得授权的脱敏历史计算单或独立编制的公用工程算例。由同一批参与者分别用现行 Excel 流程和工作台完成「首次比选并出计算书、变更最大流量并出新版、交给另一位工程师复核」。建议比较初算及变更用时中位数、报告是否与独立计算一致、校审人员能否仅凭交付件重建关键结果。试点建议目标为可比算例全部达到事先约定的数值误差、全部能追到方法与取值来源，并观察变更耗时中位数能否较现行流程降低至少 25%。这是试点目标，实际收益以测量为准。

## 范围

### 首版

- **工作台首页**展示「管径与压降」入口和可继续编辑的本地项目，并提供冷却水支管示例与项目文件导入入口。示例以明确的演示数据建立一条管线、两个工况和两个候选管径。
- **项目与计算单**支持同一项目下多条独立管线计算单。每张单记录管线编号、流向、介质、工况、候选方案和选型备注。工况定义流量、密度、动力黏度及取值依据。候选方案定义实际内径、直管长度、绝对粗糙度、沿流向高差、管件的局部阻力系数和对应依据。项目可提供共用的流速上限和阻力压降上限，缺项时页面明确标明相应判据未设置。
- **比选和复核**按工况 × 候选方案生成对比表。用户可展开任意组合，查看输入及单位、换算、方法、雷诺数、沿程损失、局部损失、阻力压降、高差项和带符号的两端静压差。阻力压降与静压差分别标注，限值校核使用阻力压降。页面在流速、阻力压降都可校核且各自满足时显示「满足已设限值」，发现确定超限时显示「超限」，其余显示「未完成校核」并给出原因。
- **工程模型**适用于稳态、单相、不可压、牛顿液体流经满流等内径圆管单段。用 Darcy–Weisbach 计算沿程损失，按输入的局部阻力系数计算局部损失。雷诺数低于 2,000 时采用层流关系，高于 4,000 时采用 Swamee–Jain 近似。两边界及中间区域显示流速和雷诺数，压降标为未判定，不把缺失的压降按零处理。模型参考 [美国 EPA EPANET 2.2 计算方法](https://usepa.github.io/EPANET2.2/12_analysis_algorithms.html)。
- **保存、交付与变更**在浏览器内用 IndexedDB 保存项目、草稿和显式保存的计算版本。旧版本可查看和对比；修改条件后可生成新版本。计算书支持浏览器打印和另存为 PDF，项目可导出 JSON，在另一浏览器导入后继续编辑。报告包含适用范围、输入、依据、方法版本、结果、限值、选型理由和版本标识。
- **最终发布**为独立的静态网页，经验证后由 GitHub Actions 发布到 GitHub Pages。公开页面包含应用和演示数据。真实项目数据在用户浏览器中处理和保存，可由用户主动导出。发布方式参见 [GitHub Pages 发布源官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

### 首版以外

首版范围止于单段等内径圆管的初算和校核。气体、两相流、非牛顿流体、变径或分支管网、泵选型、瞬态水锤、设备口径与安全阀计算不纳入首版。账户、云端数据库、多人在线校审、企业审批、自动选型、通用公式编辑器和公称直径自动换算也不纳入首版。

优先完成计算与独立复核，再做版本交接和发布。试点后，若工程师常重复录入同一批管线，先增加批量导入及项目模板。若主要需求是从管线校核继续到泵扬程初算，下一模块应引用已保存的管线版本，沿用相同的取值来源和计算书机制。换热、物料衡算与共享校审按试点需求安排。

## 验收标准

- **AC1｜示例与任务入口。** 给定首次进入工作台，当选择冷却水支管示例时，则可从填写条件开始查看两个候选管径与两个工况的四个结果，并展开任一结果查阅计算依据。
- **AC2｜工况与方案比选。** 给定一张计算单含至少两个工况及两个方案，当新增或修改任一工况、方案或显示单位时，则对比表按有效组合重算，组合可通过工况和方案名称区分，同一物理输入经支持的等价单位换算后给出一致结果。
- **AC3｜计算准确与可复核。** 给定有效的层流或湍流参考算例，当计算并展开结果时，则流速、雷诺数、摩擦因子和各压力项与独立参考结果相符。高差为负时仍按带符号高差项计算静压差，阻力压降仍以沿程与局部损失之和显示。报告可查到公式、单位和输入来源。
- **AC4｜校核与模型边界。** 给定缺失限值、超限、数值等于上限、雷诺数在过渡区或输入不合法的组合，当计算时，则分别显示未完成校核、超限、相应判据满足、压降未判定或具体字段错误。过渡区不能得到整体满足结论，明确的流速超限仍可标出。完整且均满足的组合显示「满足已设限值」，由用户选择方案。
- **AC5｜本地持久化。** 给定同一浏览器已有本地项目和草稿，当刷新或关闭后重新访问同一站点时，则可继续编辑原草稿，看到已保存的计算单和版本。
- **AC6｜版本差异。** 给定一张已有保存版本的计算单，当修改最大流量并保存新版本时，则原版本和其结论可复查，版本对比标出变化的输入、相应结果和校核状态。
- **AC7｜计算书。** 给定具有有效结果的保存版本，当预览和打印时，则浏览器可以保存版式可读的 PDF，且包含对应版本、计算范围、公式、取值依据、比选与校核结果、选型理由（填写时）；过渡区或缺少限值的行保留相应状态和说明。
- **AC8｜JSON 交接。** 给定一个有草稿和历史版本的项目，当导出并在干净的浏览器存储中导入时，则可继续编辑并对照旧版本。导入损坏或不支持的文件时显示原因，原项目保持完整。
- **AC9｜线上发布。** 给定发布工作流成功，当访问实际的 GitHub Pages 项目子路径时，则页面、静态资源、示例计算、本地保存与导出可用。浏览器网络检查确认计算、保存和导入导出没有上传项目数据。

## 测试策略

| 验收 | 验证方法 |
| --- | --- |
| AC1 | 浏览器从首页打开示例，核对四条结果、方法及取值依据可见。 |
| AC2 | 在浏览器新增工况和方案，修改一个工况确认只有相关结果改变，再用等价流量、管径单位独立复算。 |
| AC3 | 用独立计算表或参考实现对照层流、湍流的摩擦因子、分项压力、静压差及取值；含零局部阻力和正、零、负高差。 |
| AC4 | 用精确上限、缺一项判据、单项超限、过渡区内及两端点、非法数值分别核对数值与状态。 |
| AC5 | 在正常浏览会话完成输入及保存，刷新和关闭重开，检查草稿与快照。 |
| AC6 | 保留初版，修改最大流量生成新版，逐项对照输入、结果和校核差异，并重查旧版。 |
| AC7 | 对示例版本和含未判定行的版本执行打印，打开 PDF 检查中文、分页、数值和计算依据。 |
| AC8 | 用新浏览器配置导入导出的项目，校对草稿和快照，并验证非法和不兼容文件不会覆盖已有数据。 |
| AC9 | 查看发布记录与真实站点地址，在 Pages 子路径实测打开、计算、保存和导出并检查网络请求。 |
