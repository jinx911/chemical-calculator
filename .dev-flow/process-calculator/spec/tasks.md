# 工艺计算工作台首版任务清单

范围以[产品方案](proposal.md)和[工程设计](design.md)为准。T1 完成后接入页面，T2 与 T3 可独立推进。T4 至 T6 完成后，先通过 T7 本地验收，再执行 T8 发布及线上验收。

- [x] **T1｜管径比选与压降校核引擎**（AC2–AC4，`test_strategy: tdd`）。用独立参考值先建立测试，再实现单位归一化、工况与方案组合、Darcy–Weisbach 分项计算、限值校核和诊断。覆盖层流、湍流、过渡区及两端点、K 缺失与显式零、等于限值和带符号高差。
- [x] **T2｜本地项目、草稿与版本快照**（AC5、AC6，`test_strategy: tdd`）。实现 IndexedDB 仓库与索引、草稿修订号检查、快照与项目更新时间的原子保存。验证刷新恢复、旧版结果和限值保留，以及事务失败与标签页冲突处理。
- [x] **T3｜工作台与结果明细**（AC1–AC4，`test_strategy: smoke`）。复用现有基础样式，实现项目入口、独立示例、工况和方案编辑、逐项校核状态及公式明细。以冷却水示例核对两工况乘两方案，验证改一个参数只改变对应结果。
- [x] **T4｜版本比较与计算书**（AC6、AC7，`test_strategy: tdd`）。先验证比较按稳定 ID 识别参数、结果及结论变化，再接入指定快照的报告预览和打印样式。将最大流量由 45 改至 55 m³/h 后分别打印旧版、新版，核对中文、单位、公式、分页与版本对应关系。
- [x] **T5｜项目备份与恢复**（AC8，`test_strategy: tdd`）。实现版本化 JSON 导出、校验和原子导入副本。验证草稿及历史快照往返、重新映射引用，并确认不支持版本或坏引用不会改变原项目。
- [x] **T6｜静态发布产物与工作流**（AC9，`test_strategy: smoke`）。在独立仓库配置 GitHub Actions，验证通过后打包允许发布的网页、模块、样式和公开算例。以仓库子路径预览，确认资源与示例能加载，检查产物仅含公开内容。
- [x] **T7｜发布前验收**（AC1–AC9 本地部分，`test_strategy: smoke`）。在浏览器从冷却水示例走完比选、校核、保存、改工况、版本对比、PDF 及 JSON 交接。核对独立计算结果、刷新恢复、诊断及网络请求，通过后才发布。
- [ ] **T8｜GitHub Pages 发布与线上验收**（AC9，`test_strategy: smoke`）。推送已验收版本，等待 Pages 发布成功。从实际 HTTPS 地址复查资源加载、计算、保存重开与导出，核对项目数据不上传，记录站点地址和发布提交。
